# 🧮 CodeAlpha Calculator

A responsive calculator built using HTML, CSS, and JavaScript as part of my CodeAlpha Frontend Development Internship.

## 🚀 Features

- Basic arithmetic operations
- Addition, subtraction, multiplication, and division
- Clear button
- Delete button
- Decimal and percentage support
- Real-time result display
- Keyboard support
- Hover and click effects
- Responsive design

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

- `index.html` — Calculator structure
- `style.css` — Styling and responsive design
- `script.js` — Calculator functionality and keyboard support
